# 井下履带式掘进机三激光雷达 + IMU 长期稳定建图方案 v1.2（补充修正版）

# 1. 核心结论

| 修正项 | 原方案倾向 | v1.2 修正后 |
|---|---|---|
| 静止状态 | 主要按“静止截割”处理 | 拆分为“静止待机”和“静止截割” |
| 设备状态表 | 未作为主状态机输入 | 作为离散工况先验和状态机门控，不能作为里程计 |
| 前进/后退 | 由 LiDAR-IMU 判断运动 | 仍由 LiDAR-IMU 估计位移；状态表只提供方向弱先验 |
| 标靶布设 | 双柱/三柱编码组 | 改为单标靶站位、非等间距、高度/侧别/局部特征编码 |
| 标靶定位 | 标靶自身编码确定身份 | 单标靶 + 周围稳定特征共同确定候选身份和地图位置 |
| 断电续建 | 标靶/描述子/最后位姿三级重定位 | 增加设备状态历史和“标靶—局部特征锚点”验证 |

关键原则：

1. **状态表不是速度传感器，也不是里程计。** 它只能告诉系统当前设备处于什么工况，不能告诉系统走了多少米。
2. **车辆是否真实位移，必须由 LiDAR-IMU/BIEVR 配准确认。**
3. **静止待机比静止截割更适合做地图修补和截面精化。**
4. **单标靶可以落地，但必须通过周围特征、非等间距、高度和侧别提高唯一性。**
5. **标靶与周围特征关联是可行且推荐的。** 这可以把“单个高反射物”升级为“局部地标包”，显著降低单标靶误匹配风险。

# 2. 系统输入

## 2.1 传感器与状态输入

| 输入 | 数据内容 | 用途 |
|---|---|---|
| GUJ120 ×3 | 三路 16 线 LiDAR 点云、反射率、时间戳 | 建图、截面提取、标靶检测、重定位 |
| SIRIUS-F002SP | 角速度、加速度、姿态解算结果 | 点云去畸变、短时预测、振动/静止判定 |
| 设备状态工作表 | 前进、后退、截割作业、什么都不做 | 状态机门控、方向弱先验、异常检测 |
| 标靶站位表 | 单标靶链距、侧别、高度、地图坐标、局部特征包 | 单标靶识别、重定位、退化约束 |

## 2.2 设备状态工作表建议字段

| 字段 | 类型 | 说明 |
|---|---|---|
| timestamp | double / int64 | 状态更新时间，需与 LiDAR/IMU 时间基准可转换 |
| machine_state | enum | FORWARD / BACKWARD / CUTTING / IDLE |
| valid_flag | bool | 状态数据是否有效 |
| update_counter | int | 状态表更新序号，用于检测通信卡顿 |

若上位机允许拆分字段，推荐进一步拆成：

| 字段 | 取值 | 说明 |
|---|---|---|
| motion_state | FORWARD / BACKWARD / STOPPED | 仅表示工况，不表示速度或位移 |
| work_state | CUTTING / IDLE | 表示是否截割作业 |

注意：状态表显示“前进/后退”时，只表示设备处于运动指令或运动工况，不代表车体一定发生了可测位移。履带空转、卡滞、指令延迟时，状态表可能显示运动，但点云和 IMU 仍显示无位移。

# 3. 修正后的状态机

原四模式应扩展为八类状态。

| 状态编号 | 状态名称 | 进入条件 | 位姿策略 | 地图策略 |
|---|---|---|---|---|
| S0 | 初始化/IMU 对准 | 系统启动、重启或会话恢复 | 等待 IMU 稳定，加载最近地图快照 | 不写入地图 |
| S1 | 静止待机 | 状态表=什么都不做，LiDAR/IMU 判定无位移，振动低 | 位姿锁定；执行 IMU 零速/零角速校正 | 高可信更新静态子图和截面 |
| S2 | 静止截割 | 状态表=截割，LiDAR/IMU 判定无位移，振动高 | 位姿锁定；禁止假位移写入 | 连续时间去畸变；低权重鲁棒累积 |
| S3 | 前进建图 | 状态表=前进，LiDAR/IMU 确认真实位移 | 正常 LIO 配准；加入前进方向弱约束 | 扩展局部子图和全局图 |
| S4 | 后退建图 | 状态表=后退，LiDAR/IMU 确认真实位移 | 正常 LIO 配准；加入后退方向弱约束 | 更新已有区域，复核和补洞为主 |
| S5 | 指令运动但未发生位移 | 状态表=前进/后退，但 LiDAR/IMU 未检测到位移 | 位姿锁定；不按状态表积分 | 不扩展地图；记录空转/卡滞/状态延迟风险 |
| S6 | 状态冲突/安全保护 | 状态表与 LiDAR/IMU 持续冲突 | 保守估计或冻结；降低信任度 | 暂缓合并到基线图 |
| S7 | 退化保护 | Hessian 退化，长直低特征段约束不足 | 冻结退化方向或增加阻尼 | 优先使用强度、标靶和局部特征锚点 |
| S8 | 断电重启/重定位 | 系统重启、定位置信度不足或会话恢复 | 候选位姿验证后再进入正常状态 | 新会话暂存，验证后合并 |

# 4. 状态判定逻辑

## 4.1 第一级：设备状态表给出候选工况

| 状态表结果 | 候选状态 | 说明 |
|---|---|---|
| 什么都不做 | S1 静止待机 | 需要 LiDAR/IMU 确认无位移、低振动 |
| 截割作业 | S2 静止截割 | 需要 LiDAR/IMU 确认无位移、高振动 |
| 前进 | S3 前进建图 或 S5 指令运动但未位移 | 是否真实位移由 LiDAR/IMU 确认 |
| 后退 | S4 后退建图 或 S5 指令运动但未位移 | 是否真实位移由 LiDAR/IMU 确认 |
| 状态无效/超时 | S6 状态冲突/安全保护 | 降级为纯 LiDAR-IMU 判定 |

## 4.2 第二级：LiDAR/IMU 确认真实位移

| 判断项 | 推荐计算方法 | 阈值初值 |
|---|---|---|
| 点云相对位移 | 当前融合帧与最近局部子图 BIEVR/ICP 配准位移 | 连续 2～3 帧累计 >2～3cm 判为真实位移 |
| IMU 均值角速度 | 2s 滑动窗口陀螺均值 | <0.02°/s 支持静止 |
| IMU 加速度均值方向 | 加速度均值与重力方向夹角 | <2° 支持静止 |
| IMU 振动能量 | 加速度/角速度高频能量 | 高振动且均值近零，判为静止截割振动 |
| 状态表时间戳 | 当前时间 - 状态表更新时间 | >0.5～1.0s 判为状态表可能失效 |

## 4.3 判定规则

1. 状态表显示“什么都不做”，LiDAR/IMU 无位移且低振动：进入 **S1 静止待机**。
2. 状态表显示“截割”，LiDAR/IMU 无位移且高振动：进入 **S2 静止截割**。
3. 状态表显示“前进/后退”，LiDAR/IMU 确认真实位移：进入 **S3/S4**。
4. 状态表显示“前进/后退”，但 LiDAR/IMU 未确认位移：进入 **S5**，不更新位姿。
5. 状态表显示“静止”，但 LiDAR/IMU 连续确认位移：进入 **S6**，报警并以 LiDAR/IMU 保守估计为准。
6. 状态表失效时，不停止建图，但降低系统信任度，退化为纯 LiDAR-IMU 状态机。

| 状态 | 全局位姿 | 局部子图 | 截面数据库 | 备注 |
|---|---|---|---|---|
| S1 静止待机 | 锁定 | 高可信更新 | 高可信更新 | 最适合地图修补、截面精化、IMU 零偏估计 |
| S2 静止截割 | 锁定 | 鲁棒低权重更新 | 可更新，标记为振动帧 | 防止振动假位移 |

# 6. 前端估计修正

## 6.1 静止待机 S1

静止待机是低振动、高质量观测状态，应充分利用。

处理策略：

1. 位姿锁定，不更新全局轨迹。
2. LiDAR 处理频率可从 10Hz 降为 2～5Hz，降低计算负荷。
3. 点云作为高可信静态帧写入局部子图。
4. 对 IMU 执行零速/零角速更新，估计陀螺和加速度零偏。
5. 利用三雷达静态帧检查外参健康，例如监测三雷达融合重影误差。
6. 剔除人员、临时设备、车辆、管线拖拽等动态点后再写入地图。

## 6.2 静止截割 S2

静止截割是“无位移 + 强振动”。核心目标是防止振动被误判为车辆位移。

处理策略：

1. 位姿锁定，禁止把 ICP 假位移写入全局轨迹。
2. 启用连续时间点级去畸变。
3. 按 IMU 高频振动能量为点云赋不确定度权重。
4. 对粉尘、水雾、截割头、临时飞散物进行强度/时间一致性滤波。
5. 截面子图可持续累积，但应标记为“振动静止帧”。
6. 若同一截面已有静止待机帧，以静止待机帧为主，截割帧只做补充。

## 6.3 前进/后退建图 S3/S4

状态表只提供方向，不提供速度和位移。

处理策略：

1. 位移由 BIEVR 类 LiDAR-IMU 配准估计。
2. IMU 只提供短时预测和去畸变，不单独长期积分。
3. 状态表的“前进/后退”只作为弱方向先验：
   - 前进状态下，沿巷道主轴位移符号应为正；
   - 后退状态下，沿巷道主轴位移符号应为负。
4. 若配准结果长期与状态表方向相反，触发状态冲突检查。
5. 地图持久化中的“每前进 1m”应改为“估计轨迹累计位移每 1m”，该距离来自 LiDAR-IMU 估计。

## 6.4 指令运动但未位移 S5

进入条件：

- 状态表显示前进或后退；
- 连续 2～3s 内 LiDAR/IMU 未确认真实位移；
- 当前帧与局部子图配准残差稳定。

处理策略：

1. 不更新位姿。
2. 不扩展地图。
3. 记录日志：`commanded_motion_without_displacement`。
4. 若持续超过 5～10s，提示可能存在履带空转、卡滞或状态表延迟。

# 7. 单标靶工程方案

## 7.1 从多柱编码改为单标靶站位

由于现场施工要求同一安装位置只能布设单标靶，因此取消原“双柱/三柱编码组”设计，改为：

1. 每个标靶站位只安装一个反光圆柱标靶。
2. 用非等间距、安装高度、左右侧别、周围稳定特征来补足单标靶身份信息不足的问题。
3. 单标靶不直接作为唯一 ID，而是作为“候选锚点”。最终身份通过局部地图匹配确认。

## 7.2 单标靶规格建议

| 参数 | 建议值 |
|---|---|
| 形状 | 单个圆柱反光标靶，竖直安装 |
| 直径 | 100～150mm |
| 有效反光高度 | 常规 0.6～1.2m；关键重定位点 1.0～1.5m |
| 中心高度 | 1.2m / 1.5m / 1.8m 三档可选 |
| 材质 | 高反射膜包覆，被动件，不增加有源电气风险 |
| 安装位置 | 侧壁、帮部支护件或不影响通行的固定构件 |
| 伸出距离 | 尽量贴壁或小支架外伸 5～15cm，避免被设备刮碰 |
| 施工测量 | 安装后测量链距、侧别、高度、地图坐标和周围特征包 |

## 7.3 单标靶布设策略

| 区段 | 建议布设方式 | 间距/位置 | 用途 |
|---|---|---|---|
| 断电重启热点 | 热点前后不同站位各放 1 个单标靶，不在同一站位做多柱组 | 距热点 5～15m，保证至少 1 个可见 | 重启候选锚点 |
| 极低特征长直段 | 单标靶序列，非等距布设 | 20～40m，避免等距重复 | 提供纵向弱约束和回环候选 |
| 岔口/转弯/坡变 | 关键点前后各 1 个单标靶，侧别/高度错开 | 前后 5～20m | 拓扑节点识别 |
| 工作面前方 | 不同链距位置各放 1 个单标靶 | 工作面前 20～30m | 截面控制、短期重定位 |
| 普通有纹理巷道 | 可不设或稀疏设 | 40～80m | 地图健康检查 |

这里的“前后各 1 个”不是同一位置安装多个标靶，而是在不同链距位置各安装一个单标靶。

## 7.4 单标靶站位编码

可用编码维度如下：

| 编码维度 | 示例 | 作用 |
|---|---|---|
| 非等间距 | 18m、27m、41m、23m、35m 等 | 通过相邻标靶距离序列识别位置 |
| 高度分级 | 中心高度 1.2m / 1.5m / 1.8m | 增加识别维度 |
| 左右侧别 | 左帮 / 右帮 | 防止镜像误匹配 |
| 周围稳定特征 | 锚杆、支护、壁面纹理、管线固定点、硐室边缘 | 将单标靶升级为局部地标包 |
| 历史位姿先验 | 上次断电位置、当前估计链距 | 缩小候选标靶集合 |

推荐原则：不要要求单个标靶本身唯一，而是让“单标靶 + 周围特征 + 连续 3～5 个单标靶序列”在局部范围内唯一。

# 8. 标靶与周围特征关联定位方案

## 8.1 结论：可以，而且建议这样做

可以把某个单标靶与其周围稳定特征关联起来确定该标靶的定位。工程上建议将其定义为：

**标靶—局部特征锚点（Target-Context Anchor, TCA）**。

它不是只存一个反光圆柱中心点，而是存一个以标靶为中心的局部环境特征包。这样即使每个站位只有一个标靶，也能通过周围环境提高识别唯一性。

## 8.2 能用于关联的周围特征

| 特征类型 | 是否推荐 | 说明 |
|---|---|---|
| 巷道侧壁局部几何纹理 | 推荐 | 岩面起伏、喷浆粗糙度、凹凸纹理通常较稳定 |
| 顶板/底板边界轮廓 | 推荐 | 可形成局部截面签名 |
| 锚杆、锚索、钢带、支护网 | 推荐，但需确认长期稳定 | 若施工后长期不变，是很好的局部几何特征 |
| 硐室边缘、岔口、转弯、坡变 | 强烈推荐 | 拓扑唯一性强，适合做重定位热点 |
| 固定管线、固定电缆桥架 | 有条件推荐 | 必须确认不是临时移动件 |
| 水坑、泥堆、临时材料、人员、车辆 | 不推荐 | 会变化，不能作为稳定地标 |
| 工作面最前方破碎岩面 | 不推荐作为长期锚点 | 会随掘进持续变化，只适合短期局部参考 |

## 8.3 标靶—局部特征包内容

每个单标靶安装并完成建图后，建立如下特征包：

| 字段 | 内容 |
|---|---|
| target_station_id | 标靶站位编号 |
| target_center_map | 标靶中心在基线地图中的坐标 |
| target_side | 左帮/右帮/其他 |
| target_height | 标靶中心高度 |
| local_submap | 以标靶为中心半径 3～8m 的局部点云子图 |
| section_signature | 标靶所在链距附近的截面轮廓描述子 |
| intensity_patch | 标靶周围强度图块，含反光标靶和周围强度分布 |
| geometry_descriptor | 局部 BIEVR 高度图、法向量直方图、边缘/平面特征 |
| context_descriptor | Scan Context / ISC / 自定义几何强度联合描述子 |
| stable_feature_mask | 稳定特征掩码，剔除临时物体和易变区域 |
| last_verified_time | 最近一次验证时间 |
| health_status | 正常/遮挡/损坏/周围特征变化/待复核 |

## 8.4 建立标靶—局部特征锚点的流程

### 离线建库流程

1. 安装单标靶。
2. 测量标靶大致链距、侧别、中心高度。
3. 掘进机或手持扫描设备采集标靶附近 5～10m 点云。
4. 在融合地图中检测反光标靶中心。
5. 以标靶为中心裁剪局部子图。
6. 提取局部几何、强度和截面描述子。
7. 人工或半自动剔除临时物体，生成稳定特征掩码。
8. 写入标靶站位表和 TCA 数据库。

### 在线识别流程

1. 当前帧通过强度阈值检测单标靶。
2. 提取当前观测下标靶周围 3～8m 局部点云。
3. 计算当前局部特征描述子。
4. 根据历史位姿先验筛选候选标靶站位。
5. 对候选站位执行“标靶中心 + 周围特征”联合匹配。
6. 通过 ICP/BIEVR 精配准验证。
7. 若通过门限，则确认该标靶身份和当前位姿；否则标记为候选或拒绝匹配。

## 8.5 联合匹配评分

建议使用联合评分，而不是只看标靶中心点。

```text
Score = w_t * S_target + w_g * S_geometry + w_i * S_intensity + w_s * S_section + w_p * S_prior
```

其中：

| 项 | 含义 |
|---|---|
| S_target | 反光标靶中心、直径、高度、侧别匹配程度 |
| S_geometry | 周围局部几何子图匹配程度 |
| S_intensity | 周围强度图块匹配程度 |
| S_section | 附近截面轮廓签名匹配程度 |
| S_prior | 与当前历史位姿先验的一致性 |

初始权重建议：

| 场景 | w_t | w_g | w_i | w_s | w_p |
|---|---:|---:|---:|---:|---:|
| 断电后位置先验准确 | 0.30 | 0.25 | 0.15 | 0.10 | 0.20 |
| 长直低特征段 | 0.25 | 0.20 | 0.25 | 0.10 | 0.20 |
| 岔口/转弯/硐室附近 | 0.20 | 0.30 | 0.10 | 0.25 | 0.15 |
| 位姿先验很弱 | 0.20 | 0.35 | 0.20 | 0.20 | 0.05 |

## 8.6 因子图中的约束形式

单标靶本身只提供点约束，不能单独确定完整 6DoF 位姿。加入周围特征后，可形成组合约束：

```text
E = E_lio + E_target_center + E_context_submap + E_intensity + E_prior
```

其中：

```text
E_target_center = || p_observed_target - T_current^{-1} * p_map_target ||^2
```

`E_context_submap` 来自当前标靶周围局部点云与 TCA 局部子图的 ICP/BIEVR 残差；`E_intensity` 来自强度图块匹配残差；`E_prior` 来自历史位姿或断电前最后稳定位姿。

接受条件建议：

| 检查项 | 建议门限 |
|---|---|
| 标靶中心残差 | <3～5cm |
| 局部子图 ICP/BIEVR RMSE | <5～8cm |
| 描述子 Top1/Top2 分数比 | >1.3～1.5 |
| 高度/侧别一致性 | 必须一致，除非安装记录缺失 |
| 历史位姿差异 | 小先验场景下 <5～10m |

## 8.7 适用边界

标靶—周围特征关联定位有明显价值，但需要边界条件：

1. 若周围是完全光滑、重复的长直巷道，单标靶 + 周围特征仍可能不唯一。
2. 若周围特征会随施工频繁变化，不能作为长期锚点。
3. 若只看到一个单标靶且无任何历史位姿先验，不能保证全局唯一定位。
4. 若能连续看到多个单标靶，则应优先使用“单标靶序列 + 周围特征”联合匹配。
5. TCA 数据库需要定期健康检查，标靶遮挡、损坏或周边环境变化时必须标记为待复核。

# 9. 断电续建方案

## 9.1 持久化内容

除原局部子图、最新位姿、会话 ID、全局地图快照和截面数据库状态外，新增：

| 新增内容 | 用途 |
|---|---|
| 最近 30～60s 设备状态表序列 | 判断断电前是在待机、截割、前进还是后退 |
| 状态机历史序列 | 分析断电前是否处于冲突/退化状态 |
| 最后一次确认真实位移时间 | 区分“指令运动但未位移”和真实运动 |
| 最近单标靶观测记录 | 重启后辅助候选位置选择 |
| 最近 TCA 匹配记录 | 判断最近稳定局部锚点 |
| 最近截面质量状态 | 防止重启后重复写入低质量截面 |

## 9.2 重启后流程

1. IMU 对准完成。
2. 读取当前设备状态表。
3. 加载断电前最后一个稳定会话状态。
4. 若当前状态表为“什么都不做”或“截割”，优先假设设备位置未变化，但必须用当前点云与上次局部子图 ICP/BIEVR 验证。
5. 若当前状态表为“前进/后退”，不直接积分位移，必须等待 LiDAR/IMU 确认真实位移后进入 S3/S4。
6. 若检测到单标靶，先用标靶站位表生成候选，再用 TCA 局部特征包验证。
7. 若无标靶或单标靶不唯一，使用 Scan Context/ISC + BIEVR 精配准。
8. 重定位成功后创建新会话；新会话通过质量门限后再合并到基线图。

## 9.3 修正后的三级重定位链路

| 优先级 | 重定位方式 | 适用条件 | 验证方式 |
|---|---|---|---|
| 第一级 | 最后稳定位姿 + 当前局部子图验证 | 断电后设备未移动或几乎未移动 | ICP/BIEVR RMSE <3～5cm |
| 第二级 | 单标靶 + TCA 局部特征锚点 | 检测到单标靶，周围特征稳定 | 标靶中心 + 局部子图 + 强度描述子联合验证 |
| 第三级 | Scan Context/ISC + 全局候选检索 | 无标靶或标靶不唯一 | 候选关键帧检索 + ICP/BIEVR 精验证 |

说明：如果断电后设备理论上不移动，第一级应放在最前；如果现场断电重启热点标靶布设充分，第二级可与第一级并行执行，用于提高置信度。

# 10. 退化保护修正

长直巷道纵向约束弱，单标靶又不能单独提供完整 6DoF 位姿，因此退化保护采用以下组合：

1. Hessian 特征值分析识别退化方向。
2. 对退化方向增大阻尼或冻结位姿增量。
3. 使用强度辅助残差增强纵向可观测性。
4. 若检测到单标靶，使用标靶中心点约束。
5. 若该标靶存在 TCA 局部特征包，进一步使用周围特征匹配解除候选歧义。
6. 若仍无法唯一确认，则保持退化保护，不强行闭环。

退化状态下的原则：**宁可保守冻结纵向，也不要把错误标靶或错误局部特征强行合并进基线地图。**

# 12. 修正后的验收指标

## 12.1 静止状态指标

| 指标 | 验收线 | 测试方法 |
|---|---|---|
| 静止待机假位移 | <1cm/1h | 车辆无动作，统计 1h 位姿漂移 |
| 静止截割假位移 | <2cm/1h | 截割作业但车体不移动，统计 1h 位姿漂移 |
| 静止待机地图修补有效性 | 截面完整度提升，且无明显重影 | 对比修补前后截面完整度和三雷达重影 |
| 截割帧去畸变效果 | 截面径向 RMSE <5cm | 与人工测量或静止待机基准截面对比 |

## 12.2 设备状态表融合指标

| 指标 | 验收线 | 测试方法 |
|---|---|---|
| 状态表接入延迟 | <0.5s，最大不超过 1s | 对比状态表时间戳与系统时间 |
| 指令运动但未位移识别 | >95% | 模拟履带空转/卡滞，系统不得积分假位移 |
| 状态冲突检出率 | >95% | 人为制造状态表与实际运动不一致场景 |
| 前进/后退方向冲突误报率 | <2% | 正常前进/后退测试 |

## 12.3 单标靶与 TCA 指标

| 指标 | 验收线 | 测试方法 |
|---|---|---|
| 单标靶检测成功率 | >95% | 有效距离内、不同粉尘和角度下测试 |
| 单标靶中心定位误差 | <3～5cm | 与人工测量标靶中心对比 |
| 小先验范围内站位匹配成功率 | >95%，位姿不确定度 <10m | 断电重启热点测试 |
| 大先验范围下误匹配率 | <1%，无法唯一时应拒绝 | 多个相似长直段重定位测试 |
| 连续单标靶序列识别成功率 | >95% | 通过 3～5 个单标靶序列进行匹配 |
| TCA 局部特征匹配成功率 | >95% | 单标靶 + 周围特征联合匹配测试 |
| TCA 错误接受率 | <1% | 周围特征相似或变化场景测试 |
| 标靶/周边特征变化检出率 | >95% | 遮挡、损坏、临时物体干扰测试 |

## 12.4 核心截面指标保留

| 指标 | 验收线 |
|---|---|
| 截面径向 RMSE | <5cm |
| 截面轮廓完整度 | >85% |
| 同位重复误差 | <3cm |
| 断电重启成功率 | >95% |
| 纵向分段误差 | 每 50m <1% |

# 13. 实施路线

## 第一阶段：状态表接入与静止状态拆分

1. 接入设备状态工作表。
2. 完成状态表时间同步和超时检测。
3. 建立 S1/S2/S3/S4/S5/S6/S7/S8 状态机。
4. 增加状态冲突日志。
5. 验证静止待机和静止截割均不产生假位移。

## 第二阶段：状态表与 LiDAR-IMU 融合

1. 前进/后退方向弱约束。
2. 指令运动但未位移识别。
3. 状态表失效降级为纯 LiDAR-IMU 状态机。
4. 地图写入权重按状态自适应调整。
5. 截面数据库记录点云来源状态。

## 第三阶段：单标靶站位系统

1. 设计单标靶规格。
2. 形成单标靶站位表。
3. 制定非等间距、高度、侧别组合规则。
4. 实现单标靶检测和候选站位匹配。
5. 实现连续单标靶序列识别。

## 第四阶段：标靶—局部特征锚点 TCA

1. 设计 TCA 数据结构。
2. 采集每个单标靶周围 3～8m 局部子图。
3. 提取局部几何、强度、截面描述子。
4. 建立标靶站位表与 TCA 数据库关联。
5. 实现单标靶 + 周围特征联合匹配。
6. 在断电重启、长直退化段和标靶遮挡场景下验证。

## 第五阶段：井下联合验证

1. 静止待机 1h 测试。
2. 静止截割 1h 测试。
3. 前进/后退低速运动测试。
4. 指令运动但未位移模拟测试。
5. 断电重启测试。
6. 单标靶遮挡、损坏、误匹配测试。
7. TCA 周边特征变化测试。
8. 长直低特征段退化测试。

# 14. 最终摘要

修正后方案可概括为：

1. 三雷达 + IMU 仍是主建图链路，设备状态表是工况先验，不是位移传感器。
2. 静止状态必须拆成“静止待机”和“静止截割”。两者都锁定位姿，但地图写入权重和去畸变策略不同。
3. 设备状态表用于防止错误模式切换，尤其用于识别“截割但不移动”“待机且不移动”“指令运动但实际未移动”。
4. 前进/后退时，真实位移仍由 LiDAR-IMU/BIEVR 配准估计；状态表只提供方向弱约束。
5. 原双柱/三柱标靶组取消，改为单标靶站位系统。
6. 单标靶通过非等间距、高度分级、左右侧别、历史位姿先验和局部地图 ICP 进行候选识别。
7. 可以将某个单标靶与其周围稳定特征关联起来定位，推荐建立“标靶—局部特征锚点 TCA”。
8. TCA 将标靶中心、周围局部子图、强度图块、截面签名和稳定特征掩码绑定在一起，可显著提高单标靶身份识别和断电重定位可靠性。
9. 单个标靶即使加入周围特征，在无先验、低特征、重复巷道环境下仍不能保证全局唯一；此时必须结合 Scan Context、连续单标靶序列或人工确认。
10. 截面质量评价应记录点云来源状态，优先使用静止待机帧，其次使用正常运动帧和去畸变后的截割帧。
